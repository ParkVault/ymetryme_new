# Y me TRY me — Men's Collection Prototype

This is an original storefront prototype inspired by the broad category-led shopping structure of The Souled Store's men's collection page. It does not copy its branding, source code, assets, or exact layout.

## Files
- `index.html` — page structure
- `styles.css` — responsive design and styling
- `script.js` — prototype interactions

## Preview
Open `index.html` in a modern browser. An internet connection is needed for Google Fonts and the remote Unsplash demonstration images.

## Included in this prototype
- Promotional announcement bar
- Responsive header and mobile navigation
- Search panel
- Men's collection introduction and campaign hero
- Shop-by-category tiles
- Editorial promotional section
- Product grid with category, size and price filters
- Sorting controls
- Wishlist and quick-add demo interactions
- Newsletter form demo
- Responsive mobile layout

## Important limitations
This is a frontend prototype using demonstration product names, prices and remote imagery. It is not connected to a backend, inventory, customer accounts, payment gateway, shipping, order tracking or a real checkout. Quick-add and wishlist are temporary UI demonstrations. Replace all sample product information and images with client-approved assets before launch.
